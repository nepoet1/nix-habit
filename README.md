# 🔥 nix-habit v2.0 — Терминальный Хаб (Привычки + Заметки) для NixOS

Легкий, быстрый и интуитивно понятный TUI-хаб с трекером привычек, встроенной системой заметок, цитатами дня, подсчетом серий (streaks) и графиками за 14 дней. Работает из коробки без лишних зависимостей.

## 🚀 Запуск одной командой (вообще без установки)

Просто скопируйте и вставьте в терминал. Nix сам скачает и сразу запустит программу:

    nix --extra-experimental-features "nix-command flakes" run github:nepoet1/nix-habit

*(Если у вас в системе уже включены Flakes, достаточно короткой команды: `nix run github:nepoet1/nix-habit`)*

---

## ✨ Что нового в v2.0:
* **Вкладки навигации (`1`, `2` или `Tab`):** мгновенное переключение между трекером привычек и блокнотом для заметок.
* **Полноценная система заметок:** создание заметок с заголовком и датой, режим чтения с автопереносом текста и быстрое редактирование по кнопке `E`.

## 📦 Как установить в систему навсегда

### Способ 1: Быстрая установка в профиль (одной строчкой)

    nix --extra-experimental-features "nix-command flakes" profile install github:nepoet1/nix-habit

После этого хаб можно запускать в любой момент просто командой **`nix-habit`** в терминале!

### Способ 2: Декларативно через ваш системный `flake.nix`
1. Добавьте `nix-habit.url = "github:nepoet1/nix-habit";` в секцию `inputs` вашего `flake.nix`.
2. Добавьте `inputs.nix-habit.packages.${pkgs.system}.default` в `environment.systemPackages`.

## 🎮 Управление

Все подсказки всегда видны на нижней панели внутри самой программы. Горячие клавиши работают **на любой раскладке** (и на английской, и на русской):

* **`1` / `2` или `Tab`** — Переключение между вкладками **Привычки** и **Заметки**.
* **`A`** — Добавить новую привычку или создать новую заметку.
* **`Пробел` или `Enter`** — Отметить привычку выполненной / Открыть заметку для чтения.
* **`E`** *(во вкладке Заметки)* — Редактировать текст выбранной заметки.
* **`G`** *(во вкладке Привычки)* — Открыть график выполнения за последние 14 дней.
* **`Стрелки Вверх / Вниз`** (или **`J` / `K`**) — Перемещение по списку.
* **`D`** — Удалить выбранный элемент.
* **`Q`** — Выйти из программы.

## 💾 Где хранятся данные?
Все данные автоматически сохраняются локально на вашем компьютере в папке `~/.local/share/nix-habit/` (`habits.json` и `notes.json`).
