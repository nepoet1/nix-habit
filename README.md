# 🔥 nix-habit — Терминальный трекер привычек для NixOS

Легкий, быстрый и интуитивно понятный TUI-трекер привычек с цитатами дня, подсчетом серий (streaks), графиками за 14 дней и локальным сохранением. Работает из коробки без лишних зависимостей.

## 🚀 Запуск одной командой (вообще без установки)

Просто скопируйте и вставьте в терминал. Nix сам скачает и сразу запустит трекер:

```bash
nix --extra-experimental-features "nix-command flakes" run github:nepoet1/nix-habit
```
*(Если у вас в системе уже включены Flakes, достаточно короткой команды: `nix run github:nepoet1/nix-habit`)*

## 📦 Как установить в систему навсегда

### Способ 1: Быстрая установка в профиль (одной строчкой)
```bash
nix --extra-experimental-features "nix-command flakes" profile install github:nepoet1/nix-habit
```
После этого трекер можно запускать в любой момент просто командой **`nix-habit`** в терминале!

### Способ 2: Декларативно через ваш системный `flake.nix` (по фэншую NixOS)
1. Добавьте `nix-habit` в секцию `inputs` вашего `flake.nix`:
```nix
inputs = {
  nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  nix-habit.url = "github:nepoet1/nix-habit";
};
```
2. Добавьте пакет в список программ в вашем `configuration.nix` (или Home Manager):
```nix
environment.systemPackages = [
  inputs.nix-habit.packages.${pkgs.system}.default
];
```

## 🎮 Как пользоваться (Управление)

Все подсказки всегда видны на нижней панели внутри самой программы. Горячие клавиши работают **на любой раскладке** (и на английской, и на русской):

* **** — Добавить новую привычку (откроется окошко: введите название и нажмите `Enter`).
* **** или **** — Отметить привычку выполненной на сегодня (или снять галочку).
* **** (или ** / **) — Перемещение по списку привычек.
* **** — Открыть график выполнения за последние 14 дней и процент успеха.
* **** — Удалить выбранную привычку.
* **** — Выйти из программы.

## 💾 Где хранятся мои привычки?
Все данные автоматически сохраняются на вашем компьютере в файле `~/.local/share/nix-habit/habits.json`.
